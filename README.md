# Simulador BST · Árbol Binario de Búsqueda

Simulador interactivo para ver paso a paso cómo funciona un árbol binario de búsqueda (BST).

**Demo:** https://dnielbermudez.github.io/simulador-bst/

## Qué hace
- Insertar, buscar y eliminar números, o insertar una lista completa.
- Eliminación en sus 3 casos (hoja, un hijo, dos hijos) con sucesor o predecesor.
- Mínimo, máximo y recorrido inorden.
- Código en Java resaltado línea por línea, con `true`/`false` en cada condición.
- Explicación paso a paso, contador de comparaciones y altura del árbol.
- Barra para elegir el paso, barra de velocidad y atajos de teclado (← → espacio).

Es un solo archivo `index.html`, sin dependencias.
